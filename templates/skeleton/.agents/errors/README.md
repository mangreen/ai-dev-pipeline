# Errors (ERR) — show-stoppers, pitfalls, anti-patterns

Create `ERR-<YYYYMMDD>-<brief>.md` the moment a critical error or a trap is discovered, so that
nobody has to rediscover it.

## Template

```markdown
# ERR: <Error title>
Date: YYYY-MM-DD
Severity: Critical | High | Medium

## Description

## Root Cause

## Solution

## Prevention
(How to avoid it in the future.)
```
